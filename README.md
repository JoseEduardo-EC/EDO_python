# Resolução de Equações Diferenciais (EDOs)

Este repositório contém a resolução analítica e numérica de várias EDOs utilizando Python e Jupyter Notebook.

## Como executar localmente

1. Clone o repositório.

2. Crie um ambiente virtual:
```bash 
python -m venv .venv
```
3. Ative o ambiente virtual:
```bash 
source .venv/bin/activate
```

4. Instale as dependências: 
```bash 
pip install -r requirements.txt
```

5. Inicie o Jupyter: 
```bash 
jupyter notebook
```
